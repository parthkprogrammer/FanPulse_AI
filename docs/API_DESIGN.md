## 1. Global API Standards & Conventions

### 1.1 Base URL & Versioning
* All REST endpoints are prefixed with the base path and version:  
  **`https://api.fanpulse.ai/api/v1`** (or `http://localhost:8080/api/v1` for local development).
* Semantic URL structure adheres to standard resource-oriented REST conventions (plural nouns, kebab-case for multi-word paths, camelCase for JSON properties).

### 1.2 Request & Response Formats
* **Content-Type:** `application/json` (required for all request bodies).
* **Accept:** `application/json`.
* **Timestamps:** ISO-8601 extended format with UTC offset (`YYYY-MM-DDTHH:mm:ssZ`).
* **Decimals/Numbers:** Floating-point numbers with defined precision (e.g., economy rate `4.25`, fantasy points `64.50`).

### 1.3 Authentication & Authorization Scheme
* **Header:** `Authorization: Bearer <JWT_TOKEN>`
* Stateless Bearer token containing user identity and granted roles (`ROLE_USER`, `ROLE_ADMIN`).
* Protected endpoints return `401 Unauthorized` if the token is missing, expired, or invalid.
* Endpoints restricted to elevated privileges return `403 Forbidden` if the authenticated user lacks the required role.

### 1.4 Standard Error Response Envelope
All error responses generated by `@RestControllerAdvice` return a standardized, machine-readable envelope (`NFR-REL-03`):

```json
{
  "status": 400,
  "error": "Bad Request",
  "message": "Validation failed for one or more fields.",
  "timestamp": "2026-11-02T19:45:00Z",
  "path": "/api/v1/fantasy-teams",
  "fieldErrors": [
    {
      "field": "playerIds",
      "rejectedValue": [1, 2, 3],
      "message": "A fantasy team must contain exactly 11 players."
    }
  ]
}
```

### 1.5 Standard Pagination Envelope
All listing endpoints support standard query parameters: `page` (0-indexed, default: `0`), `size` (default: `20`, max: `100`), and `sort` (e.g., `matchDate,desc`):

```json
{
  "content": [],
  "page": 0,
  "size": 20,
  "totalElements": 48,
  "totalPages": 3,
  "first": true,
  "last": false
}
```

## 2. Authentication & User Management APIs (AUTH)

### 2.1 User Registration
* **HTTP Method:** `POST`
* **URL:** `/api/v1/auth/register`
* **Description:** Creates a new user account with role `ROLE_USER` (`FR-AUTH-01`).
* **Authentication:** Public (None).

#### Request DTO: `RegisterRequest`
```json
{
  "email": "fan@example.com",
  "password": "Password123!",
  "displayName": "CricketGuru"
}
```

#### Validation Rules
* `email`: `@NotBlank`, `@Email`, max 255 chars. Unique across database (`FR-AUTH-02`).
* `password`: `@NotBlank`, `@Size(min = 8, max = 100)`. Must include at least 1 letter and 1 digit (`PD-07`).
* `displayName`: `@NotBlank`, `@Size(min = 2, max = 50)`.

#### Response DTO: `AuthResponse` (HTTP 201 Created)
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "tokenType": "Bearer",
  "expiresIn": 1800,
  "user": {
    "id": 101,
    "email": "fan@example.com",
    "displayName": "CricketGuru",
    "role": "ROLE_USER",
    "createdAt": "2026-11-02T19:45:00Z"
  }
}
```

#### Error Responses
* **400 Bad Request:** Missing fields, invalid email format, or weak password.
* **409 Conflict:** Email address already registered (`FR-AUTH-02`).

* **URL:** `/api/v1/auth/login`

* **401 Unauthorized:** Invalid credentials (`FR-AUTH-04`). Message does not reveal whether email or password was incorrect.

## 5. Fantasy Team Management APIs (FANTASY)

### 5.1 Create Fantasy Team
* **HTTP Method:** `POST`
* **URL:** `/api/v1/fantasy-teams`
* **Description:** Authenticated user drafts a fantasy team for an upcoming match (`FR-FANTASY-01`, `UC-05`).
* **Authentication:** Required (`ROLE_USER` or `ROLE_ADMIN`).

#### Request DTO: `CreateFantasyTeamRequest`
```json
{
  "matchId": 1,
  "teamName": "Royal Strikers XI",
  "captainPlayerId": 101,
  "viceCaptainPlayerId": 105,
  "playerIds": [101, 102, 103, 104, 105, 106, 201, 202, 203, 204, 205]
}
```

#### Validation Rules (Enforces Business Rules `BR-TEAM-*`)
* `matchId`: `@NotNull`. Match status must be `UPCOMING` (`BR-TEAM-06`).
* `teamName`: `@NotBlank`, `@Size(min = 3, max = 100)`.
* `playerIds`:
  * Must contain **exactly 11** distinct player IDs (`BR-TEAM-01`, `FR-FANTASY-02`).
  * No duplicate players permitted (`UNIQUE` constraint, `BR-TEAM-01`).
  * All 11 players must belong to the active match roster (`BR-TEAM-05`).
  * Lineup must include players from **both competing teams** (`BR-TEAM-02`).
  * Composition minimums: at least 1 Batter, 1 Bowler, 1 All-Rounder, 1 Wicket-Keeper (`BR-TEAM-03`).
* `captainPlayerId` and `viceCaptainPlayerId`:
  * Both must exist in the selected `playerIds` array (`BR-TEAM-04`).
  * Captain and Vice-Captain cannot be the same player: `captainPlayerId <> viceCaptainPlayerId` (`BR-TEAM-04`).

#### Response DTO: `FantasyTeamDetailResponse` (HTTP 201 Created)
```json
{
  "id": 501,
  "userId": 101,
  "matchId": 1,
  "teamName": "Royal Strikers XI",
  "captainPlayerId": 101,
  "viceCaptainPlayerId": 105,
  "totalPoints": 0.00,
  "isLocked": false,
  "createdAt": "2026-11-02T19:45:00Z",
  "players": [
    {
      "playerId": 101,
      "playerName": "Virat Kohli",
      "country": "India",
      "role": "BATTER",
      "isCaptain": true,
      "isViceCaptain": false
    },
    {
      "playerId": 105,
      "playerName": "Jasprit Bumrah",
      "country": "India",
      "role": "BOWLER",
      "isCaptain": false,
      "isViceCaptain": true
    }
  ]
}
```

#### Error Responses
* **400 Bad Request:** Team composition constraint violated (e.g., `< 11` players, missing role, duplicate players).
* **403 Forbidden:** Target match has already started or completed (`BR-TEAM-06`).
* **404 Not Found:** `matchId` or one of the `playerIds` does not exist.

```json
{
  "teamName": "Royal Strikers Prime",
```

* Enforces all 11-player composition constraints identical to team creation.

#### Response DTO: `FantasyTeamDetailResponse` (HTTP 200 OK)
* Returns updated team representation.

* **Description:** Generates an AI-driven, grounded natural-language explanation of a match's current or completed situation (`FR-AI-01`, `FR-AI-02`, `UC-08`).

#### Request DTO: `AiMatchSummaryRequest`
